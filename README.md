# 산업안전산업기사 필기 CBT

전기기능사 CBT의 React·TypeScript·Vite 화면과 학습 기능을 재사용한 비공식 학습 앱입니다. 기준 코드는 `YunSangYeong/electrician-cbt`의 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`, 적용 문서 표준은 CBT site standard 1.3.1입니다. 스킬 전체는 `.agents/skills/cbt-site-standard/`, 연결 지침은 `AGENTS.md`에 있습니다. 계정 공통 스킬 설치를 뜻하지 않습니다.

## 시험 설정과 확인 상태

설정은 `src/qualification.ts`에서 관리합니다. **아래 규칙은 공식 원문 대조가 끝나지 않은 잠정 설정입니다.** 2026-10-20 Q-Net 종목 상세 요청이 프록시의 HTTP 403으로 차단됐습니다. 공식 시험을 검증해 재현했다고 주장하지 않습니다.

- 과목: 산업재해 예방 및 안전보건교육 / 인간공학 및 위험성 평가·관리 / 기계·기구 및 설비 안전 관리 / 전기 및 화학설비 안전 관리 / 건설공사 안전 관리
- 각 과목 20문항, 전체 100문항, 150분, 객관식 4지선다.
- 과목별 100점 만점(각 5점), 전체 평균 60점 이상이며 모든 과목 40점 이상. 미응답은 오답.
- 설정에 대한 평균 59/60점, 과목별 정답 7/8개 경계를 테스트했습니다. 테스트 통과는 시험 규칙 자체의 공식 확인을 대신하지 않습니다.
- 공식 확인 대상: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=2381

## 실제 문제은행

**1,000문항은 25개 계산 연습 유형 × 유형별 수치 조건 40개입니다.** 독립 개념 1,000개 또는 기출 1,000개가 아닙니다. 과목별 200개이며 원문 기출 0개·복원 0개·자체 제작 1,000개입니다. 전기기능사 문제는 복사하지 않았습니다.

| 과목 | 독립 계산 유형 | 등록 수 |
| --- | --- | ---: |
| 산업재해 예방 및 안전보건교육 | 도수율·강도율·연천인율·평균 손실일수·교육 이수율 | 200 |
| 인간공학 및 위험성 평가·관리 | 직렬/병렬 신뢰도·위험 점수·작업 모멘트·무오류 확률 | 200 |
| 기계·기구 및 설비 안전 관리 | 운동에너지·유압 힘·주변 속도·기어 회전수·정지거리 | 200 |
| 전기 및 화학설비 안전 관리 | 전류·발열·전력·용액 희석·부피 ppm | 200 |
| 건설공사 안전 관리 | 평균 응력·안전율·하중 모멘트·굴착량·분포하중 합력 | 200 |

문항은 일반 공학·확률·통계 지식에 따라 자체 작성했습니다. 문제에서 가정·식·계산 관례를 명시하며 법정 안전 수치나 실제 작업의 적합성을 판정하지 않습니다. 외부 교재나 공식 자료를 읽었다고 인용하지 않습니다. `sourceUrl`은 생성 원고의 위치이며 외부 정답 증빙이 아닙니다.

공통 문장·공식·입력·단위는 내부 검토했고, Python Decimal 생성기와 별개의 JavaScript 계산 경로로 등록된 1,000개 답안·보기·반올림을 검증합니다. **외부 전문가 검수, 공식 출제기준 대조, 전 범위 개념·법규 검증은 미완료**입니다. `reviewed`는 이 제한된 내부 검토를 의미합니다. 수량 기준은 내부 검토 기준으로 충족하지만, 공식 대조를 포함한 표준 전체 인수 완료로 처리하지 않습니다. 학습 범위는 계산 기초에 편중되어 있어 이 은행만으로 시험 전 범위를 대비할 수 없습니다.

`python scripts/generate_bank.py`로 JSON과 등록 양식을 결정적으로 재생성합니다. 시각·난수에 의존하지 않고 ID와 순서를 유지합니다. 숫자 변형은 `family`로 묶습니다. 시험에는 과목별로 확보된 5개 유형을 우선 포함한 뒤, 남은 15자리는 중복 ID 없이 보충하므로 한 시험에 같은 유형의 다른 수치 문제가 포함됩니다. 검증 대기·오류·로컬 등록분은 기본 1,000개 집계에서 제외했습니다.

## 기능과 데이터

대시보드, 실전시험, 랜덤 풀이, 오답 복습, 북마크, 과목별 통계, JSON/CSV 로컬 등록·검수·내보내기를 제공합니다. 두 모드에서 답안을 선택한 뒤 Space로 다음 문제에 이동하며 마지막 시험 문제에서 자동 제출하지 않습니다. 학습 기준/연도 선택 메뉴와 상단 상시 면책 배너는 없습니다. 출처·검수 한계는 문제은행 관리와 문항 해설에 표시합니다.

시험 시작·종료 절대 시각과 답안을 저장하고 새로고침·재접속 때 만료 여부를 확인합니다. 제출 전 정답을 숨기며 과락을 반영합니다. 저장 namespace는 `industrial-safety-associate-cbt:v1`입니다. 응답은 최근 5,000개, 시험 결과는 최근 30회까지 저장하며 화면 통계도 이 보관 범위를 기준으로 합니다. 백업 다운로드를 지원하지만 **백업 복원 UI는 없습니다**. 초기화에는 확인이 필요하며 기본 문제은행은 지우지 않습니다. 손상 데이터는 자동 덮어쓰지 않고 저장 실패 경고를 표시합니다. iframe·시크릿 모드 등 브라우저 저장 제한이 적용될 수 있습니다.

## 실행과 검증

Node.js `24.19.0`, npm lockfile 사용. 서버·DB·로그인·유료 API가 필요하지 않습니다.

```sh
npm ci
npm run dev
npm test
npm run build
# 최초 브라우저 설치(호스트에 Chromium이 없다면)
npx playwright install --with-deps chromium
npm run test:e2e
```

현재 클라우드에는 `/usr/bin/chromium`이 있어 다음 명령을 사용합니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

로컬 단위 1,018개와 PC/모바일 브라우저 시나리오 30개가 통과했습니다. 원격 validate도 성공했지만 Pages 배포는 사이트 조회 404로 실패했습니다. 현재 검증 결과와 차단된 항목은 [검증 기록](docs/validation.md)에 있습니다. PC Chromium과 Pixel 7 에뮬레이션이며 실기기 검증과 다른 브라우저 검증은 별개입니다.

## GitHub Pages

Vite base는 `/Industrial-Engineer-Industrial-Safety-CBT/`입니다. 예상 공개 주소는 아래와 같으며 **배포 성공 및 공개 동작 확인 전까지 예정 주소**입니다.

https://YunSangYeong.github.io/Industrial-Engineer-Industrial-Safety-CBT/

`.github/workflows/pages.yml`은 main push/PR에서 검증하고 `workflow_dispatch` 또는 main의 커밋 메시지에 명시적으로 `[deploy-pages]`를 넣은 push에서만 배포합니다. 일반 push/PR은 검증만 수행합니다. 수동 배포도 테스트가 통과해야 합니다. 이번 작업에서 사용자는 에이전트의 배포 실행까지 명시적으로 요청했지만, Git 읽기·푸시 권한과 GitHub API/Pages 설정 권한은 별개입니다. 직접 API가 차단되어 이번 요청에서는 배포 표식이 있는 push로 GitHub Actions의 배포를 시도하며, Actions 공개 웹 화면에서 결과를 확인합니다. Pages가 아직 활성화되지 않았다면 관리자 설정이 필요합니다. 미실행을 배포 성공으로 기록하지 않습니다.

**실제 배포 시도 결과:** 앱 커밋 `1c89bd6`의 [Actions 실행](https://github.com/YunSangYeong/Industrial-Engineer-Industrial-Safety-CBT/actions/runs/39402005917)에서 validate는 성공하고 deploy는 Pages 조회 404로 실패했습니다. 아래 최초 Pages 설정이 필요합니다.

직접 배포하는 경우:

1. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다.
2. Actions → **Test and deploy GitHub Pages** → Run workflow에서 **main**을 선택합니다.
3. validate와 deploy가 모두 통과한 정확한 커밋을 확인합니다.
4. 위 주소에서 새로고침·실전/랜덤·Space·저장·모바일 메뉴를 확인합니다. 블로그 iframe은 기본 주소를 사용합니다.
